# CEYLON INNOVATES
### IMAGINE. CREATE. INNOVATE.

A responsive website design and development project created as part of a self-initiated digital media and technology portfolio.

---

## About the Project

Ceylon Innovates is a fictional Sri Lankan organization concept designed to promote technology, creativity, digital education and innovation.

This project demonstrates my skills in website design, frontend development, graphic design and digital content creation.

The website aims to present an engaging digital platform that highlights innovative ideas, technological developments and creative opportunities.

## Project Objectives

- Design a modern and user-friendly website.
- Develop a responsive website layout.
- Present digital content in an organized manner.
- Showcase graphic design and promotional materials.
- Demonstrate practical frontend development skills.

## Technologies Used

- HTML5
- CSS3
- Acode Code Editor
- GitHub

## Website Features

- Home section
- About Us section
- Our Focus section
- Creative Work gallery
- Events section
- Contact section
- Responsive layout
